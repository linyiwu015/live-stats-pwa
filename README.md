# 直播数据统计

面向视频号直播团队的管理型 PWA。主持人每天用手机录入直播间数据，管理员查看全员合计、月度主持次数、平均在线高峰和柱状趋势。

## 已实现功能

- 手机号登录，初始密码默认为手机号后 6 位
- 登录状态长期有效，用户可自行修改密码
- 管理员新增、编辑、停用、删除主持人账号
- 为主持人分配可用直播间，并设置是否可查看全员统计
- 日期默认当天，可通过滑动选择器手动修改
- 开播时间和直播时长均使用滑动选择器
- 在线高峰人数手工填写，支持加减快捷调整
- 三个视频号直播间的数据记录、修改和删除
- 月度主持次数、直播总时长、平均高峰、最高在线合计
- 按主持人统计月度主持次数与平均在线高峰
- 可按主持次数、直播时长、高峰人数切换柱状趋势
- 管理员生成邀请二维码，主持人扫码加入
- Android Chrome 可直接安装为桌面 App（PWA）
- 离线可录入，联网后自动同步
- 本地导出/导入 JSON 备份
- 管理员可自定义统计项（名称、类型、选项），可新增/删除/编辑统计项
- 固定唯一管理员账号（手机号 13957116161），仅管理员可见“人员”管理
- 首页直接打卡填写；记录与统计集中在第二页；统计范围支持今日/昨日/本月/今年
- 打卡项支持“有无违规”（选“有”自动展开违规原因与处罚结果）
- 直播间名称管理员可自定义；用户可设置“只能查看自己数据”
- 所有用户可修改自己的头像与名称；按主持人统计显示头像
- 绿色主题配色；返回键逐级返回，仅在一级菜单时退出
- 团队数据使用 AES-GCM 加密后同步

## 数据同步说明

当前版本使用经过验证的公共 MQTT WebSocket 服务同步数据：

- 地址：`wss://broker.hivemq.com:8884/mqtt`
- 每个团队使用随机团队码派生出独立主题
- 数据在手机端加密后再上传，服务端只看到密文
- 每台设备保留本地缓存，断网期间仍可查询和录入
- 联网后自动发布最新版本，并保留最后一个团队状态

正式商用建议改为自建 MQTT、私有云函数或专有后端。无论使用哪种后端，团队码都应妥善保管，遗失后将无法解密已有云端数据。

## 首次使用

1. 管理员打开应用，选择“创建新团队”。
2. 填写团队名称、管理员姓名、手机号并创建。
3. 在“人员”页面新增主持人，设置授权直播间。
4. 点击“生成二维码”，让主持人在手机浏览器中扫描。
5. 主持人安装到桌面后，使用手机号和初始密码登录。
6. 主持人进入“记录”，点击右下角“＋”录入直播数据。

## 安卓安装

1. 使用 Android Chrome 打开应用地址。
2. 点击右上角“⋮”。
3. 选择“安装应用”或“添加到主屏幕”。
4. 确认后桌面会出现独立图标，打开时无浏览器地址栏。

应用内置“安装到手机桌面”按钮，Chrome 支持一键安装时会自动调用系统安装提示。

## 部署与安装（重要）

> 注意：Gitee Pages 已停止提供服务，仓库“服务”菜单里已无“Gitee Pages”选项，无法再用 Gitee Pages 托管。

本项目使用浏览器 Web Crypto（crypto.subtle）做密码哈希（PBKDF2）和团队数据加密（AES-GCM），**必须在 HTTPS 安全上下文下运行**，不能直接用 `file://` 打开，也不能用局域网 `http://IP` 访问（否则登录/加密会失效）。

### 方式一：免费静态托管（推荐，可安装 PWA）

任选一个免费 HTTPS 静态托管，把本目录全部文件上传即可：

- GitHub Pages：`https://<用户名>.github.io/live-stats-pwa/`
- Cloudflare Pages：`https://<项目>.pages.dev`（国内访问相对稳定）
- Netlify：`https://<项目>.netlify.app`
- 腾讯云托管 CloudBase / EdgeOne Pages（国内访问最快，需要腾讯云账号，可能需实名）

部署得到 HTTPS 地址后，用 Android Chrome 打开该地址，菜单“安装应用/添加到主屏幕”即可装到手机桌面；把该地址生成二维码即可扫码安装。

### 方式二：安卓 APK（真·桌面图标，可离线）

用 Android Studio 新建一个 WebView 工程，使用 WebViewAssetLoader 以 `https://appassets.androidplatform.net` 安全源加载本目录资源，即可打包成 APK，安装后桌面显示独立图标，断网也能打开界面，联网自动同步。

### 本地调试

桌面浏览器可用任意静态服务器在 `http://localhost` 下运行（localhost 属于安全上下文）：

```bash
npx serve .          # 或
python -m http.server 8000
```

然后浏览器打开 `http://localhost:8000`。手机真机需通过 HTTPS 地址访问。
